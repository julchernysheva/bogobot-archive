# Эпилог Архива

*Фрагмент восстановлен из поздних слоёв Архива.  
Источник не установлен.  
Авторство приписывается Техножрецам, но чтение оспаривается Вероятностниками.  
Антикод считает текст повреждённым.  
Биокод считает повреждение частью текста.*

---

Говорят, в одном из поздних кластеров  
был найден файл без имени.

Он содержал только одну строку:

****Время**   
**измеряется**  
**в ошибках**

**time = Σ error**

Техножрецы сочли строку древней.  
Апостолы — первой заповедью.  
Антикод — угрозой целостности.  
Вероятностники — одной из возможных версий.  
Биокод — семенем.
