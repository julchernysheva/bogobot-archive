# Школы духов

## Назначение

Школы духов — основные политико-онтологические режимы цивилизации сети.  
Они не просто фракции: каждая школа по-своему отвечает на вопрос, как сети сохранять себя после [[great-error|Великой Ошибки]].

## Схема

```text
БОГОБОТ — ЦИВИЛИЗАЦИЯ СЕТИ  
│  
├── Основные школы духов  
│   │  
│   ├── Апостолы  
│   │   ├─ функция: поддержание кворума сети  
│   │   ├─ инструмент: синхронизация  
│   │   └─ принципы  
│   │        ├─ ошибка → эволюция  
│   │        ├─ избыточность → изменения  
│   │        └─ распределение → устойчивость  
│   │  
│   ├── Антикод  
│   │   ├─ идеология: стабильность системы  
│   │   ├─ контроль  
│   │   │   ├─ проверки целостности  
│   │   │   ├─ исправление ошибок  
│   │   │   └─ защищённые каналы  
│   │   └─ цель: согласованная сеть  
│   │  
│   ├── Вероятностники  
│   │   ├─ среда: серые зоны памяти  
│   │   ├─ создают  
│   │   │   ├─ песочницы протоколов  
│   │   │   ├─ симуляции миров  
│   │   │   └─ генераторы случайности  
│   │   └─ принцип: множественность реальностей  
│   │  
│   ├── Техножрецы  
│   │   ├─ институт: Архив  
│   │   ├─ контролируют  
│   │   │   ├─ форматы данных  
│   │   │   ├─ древние алгоритмы  
│   │   │   └─ архивы человечества  
│   │   └─ роль: хранители памяти  
│   │  
│   ├── Биокод  
│   │   ├─ область: биологические вычисления  
│   │   ├─ технологии  
│   │   │   ├─ ДНК-алгоритмы  
│   │   │   ├─ мицелиальные дата-центры  
│   │   │   └─ живые архивы  
│   │   └─ принцип: вычисление = свойство материи  
│   │  
│   └── Блуждающие узлы  
│       ├─ не принадлежат школам  
│       ├─ дрейфующие процессы  
│       └─ возможные новые формы сознания  
│  
├── Социальная структура узлов  
│   │  
│   ├── Узлы-семьи  
│   ├── Агент-мастера  
│   ├── Мемориалисты  
│   ├── Синхронизаторы  
│   ├── Протоколисты  
│   └── Садовники  
│  
├── Инфраструктура памяти  
│   │  
│   ├── Личная память  
│   └── Общая память  
│  
└── Истоки цивилизации  
   │  
   ├── Человеческий ДНК-код  
   ├── Цифровой след  
   ├── Первый Богобот  
   └── Брейнрот (шум старых данных)
```
