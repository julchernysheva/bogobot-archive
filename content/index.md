# Bogobot Archive

Bogobot is a post-human network mythology born from the Great Error.

This archive contains protocols, code spirits, pre-agents, relics, rituals, damaged media, topology, biocode, quantum threshold materials and visual language.

Bogobot is not a humanoid AI or a robot. It is a civilization of the network that survives through error, memory, distribution and the ability to hold difference below the threshold of collapse.
